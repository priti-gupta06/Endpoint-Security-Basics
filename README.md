# Endpoint-Security-Basics

## Introduction
This project focuses on understanding basic endpoint security controls used to protect laptops, desktops, and workstations from cyber threats.

## Objectives
- Understand endpoint security.
- Identify common endpoint protection methods.
- Learn about antivirus and anti-malware.
- Understand firewalls and security updates.
- Learn the importance of screen locking.
- Understand Endpoint Detection and Response (EDR).

## Security Controls Covered
1. Antivirus and Anti-malware
2. Operating System Updates
3. Firewall Protection
4. Screen Locking
5. Strong Passwords
6. Disk Encryption
7. Data Backup
8. Safe Browsing
9. USB Security
10. EDR Monitoring

## Deliverable
An Endpoint Security Checklist covering essential security controls for laptops and desktop computers.

## Tools Used
- Google Docs

## Learning Outcomes
Learned how endpoint security protects devices and reduces cybersecurity risks through preventive security controls and monitoring.

## Conclusion
Endpoint security is important for protecting devices and organizational data. Basic practices such as antivirus protection, regular updates, firewall configuration, and screen locking help improve device security.
